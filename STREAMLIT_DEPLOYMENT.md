# Free interface demo

1. Sign in to https://share.streamlit.io/ with GitHub.
2. Create an app with repository `RR910506/ad-doctor-automation`.
3. Select branch `streamlit-community-demo`.
4. Main file: `ad_doctor/community_app.py`.
5. Choose Python 3.12 in advanced settings, then deploy.

The adjacent `ad_doctor/requirements.txt` supplies Python dependencies.
Do not add API keys or upload real subscriber data to this public demo.
All examples are synthetic, even when real brand/publication names appear.
Navigation, filters, research panels, carousel views, and quality-review examples
are interactive. Imports, approvals, scraping, publishing, email and provider
calls are blocked. The legacy application cannot be opened in this demo.
No database or persistent disk is required; no Chromium installation is needed.

Community Cloud may sleep when unused. This deployment is an interface demo,
not the private production service. Deploying private team data and live actions
requires authentication and persistent storage as a separate step. Check the
host's current free-plan terms before relying on it for ongoing operations.
